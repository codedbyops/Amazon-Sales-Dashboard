# Amazon-Sales-Dashboard
Amazon Ecommerce Sales Dashboard | Power BI

Project Overview:

This project presents an interactive Amazon Ecommerce Sales Dashboard developed using Microsoft Power BI. It provides a visual overview of sales performance, profitability, product categories, customer sales, and payment methods to support business analysis and data-driven decision-making.

Project Objectives:

- Analyze overall sales and profit performance.
- Compare sales across different states and customers.
- Understand product category and sub-category performance.
- Analyze monthly profit trends.
- Examine customer payment preferences.
- Enable interactive data exploration using dashboard filters.

Tools & Technologies:

- Microsoft Power BI Desktop
- DAX (Data Analysis Expressions)
- Data Visualization
- Interactive Slicers and KPI Cards

Dashboard Features:

- Sales by State: Compares sales performance across geographical regions.
- Quantity by Category: Shows the distribution of quantities across product categories.
- Monthly Profit Analysis: Tracks profit trends throughout the year.
- Sales by Customer: Compares sales across customers.
- Quantity by Payment Mode: Shows the distribution of transactions across payment methods.
- Profit by Sub-Category: Compares profitability across product sub-categories.
- Interactive Filters: Quarter and state slicers allow users to explore different segments of the data.

How to View the Project:

- Download the .pbix file from the dashboard/ folder.
- Open it using Microsoft Power BI Desktop.
- Interact with the quarter and state slicers to explore the dashboard.
- Refer to the PDF export for a quick preview.
